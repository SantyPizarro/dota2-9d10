# 🎮 dota2-9d10 (Dota 2 Remote Match Accepter)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-brightgreen.svg)](https://www.python.org/)

**dota2-9d10** es un bot interactivo de Discord para dota 2. Detecta automáticamente cuándo buscas partida, te notifica al celular con una captura en cuanto salta la partida y te permite **pulsar un botón para aceptarla remotamente**.

---

## 📱 Comandos Disponibles en Discord

| Comando | Descripción |
| :--- | :--- |
| `/status` | Muestra el estado del monitor, proceso de Dota 2 y usuarios autorizados. |
| `/test` | Envía una alerta interactiva de prueba a Discord. |
| `/screen` | Captura la pantalla actual y la envía a Discord. |
| `/pause [minutos]` | Pausa temporalmente al bot. |
| `/resume` | Reanuda al bot. |
